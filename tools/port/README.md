# tools/port — 게임 업데이트 간 좌표 이식

게임이 업데이트되면 `번역_마스터.json` 의 오프셋이 전부 무효가 됩니다.
이 폴더의 도구들은 **내용 기반**으로 구 버전 좌표를 새 버전 좌표에 대응시킵니다.

절차와 배경은 [../../docs/PORTING.md](../../docs/PORTING.md) 를 먼저 읽으세요.

| 파일 | 역할 |
|---|---|
| `port_lib.py` | NSO 로더 · 문자열영역 스캔 · φ(문자열 오프셋 매핑) 구축 |
| `build_maps.py` | φ 생성 + ψ(RELA 엔트리 인덱스 매핑, patience diff) 생성 → 캐시 |
| `port_master.py` | `exe` / `exe_ext` 를 새 좌표로 옮기고 **원문 일치를 바이트 검증** |
| `extract_pool.py` | 구 베이스에서 `(원문 → 잘리지 않은 전체 문장)` 역추출 → `exe_pool` 섹션 |
| `rdb_port.py` | 내용이 바뀐 CHK 만 **사전(원문→번역) 기반**으로 재매핑 |
| `scan_new.py` | 새 바이너리 절대 스캔 — 신규/미번역 문자열 수색 |
| `NEW_NAMES_KO.py` | v1.8.0 → v1.15.0 때 추가한 신규 선수명·소개문 번역표(기록) |

## ⚠ 주의

- 이 스크립트들은 **일회성 이식 작업 기록**입니다. 두 버전의 원본 경로가
  **작성 당시 절대경로로 하드코딩**되어 있으니 그대로 실행하지 말고 상단 상수를 고쳐 쓰세요.
- `build_maps.py` 는 `C:\pawa_port\cache` 에 φ/ψ 를 pickle 로 캐시합니다.
- 순서: `build_maps` → `port_master` → `extract_pool`(최초 1회) → `rdb_port` → `scan_new`.

## 이식 실적 (게임 v1.8.0 → v1.15.0)

| 대상 | 결과 |
|---|---|
| `exe` 오프셋 | 182,787 → **182,767 확정** (모호 0 · 소실 20 · 내용 불일치 0) |
| RELA 엔트리 ψ | 802,618 중 **779,192 매핑** (단조성 위반 0) |
| `exe_ext` 문장 | 5,269 중 **5,243 이식**(24B 연속성 유지) |
| `exe_pool` | safe28 에서 **34,575건 역추출** |
| RDB | 431개 대상 중 내용이 바뀐 것은 **7개**뿐 → 사전 기반 재매핑 |
| 신규 번역 | exe **51건** · RDB **605건** |
