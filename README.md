# 실황 파워풀 프로야구 2024-2025 (Switch) 한국어 팬 번역

Nintendo Switch 『実況パワフルプロ野球2024-2025』(타이틀 ID `0100d1c01c194000`)의 한국어 팬 번역
프로젝트입니다. **게임 파일은 이 저장소에 포함되어 있지 않습니다.** 본인이 소유·덤프한 원본에
xdelta 패치를 적용하는 방식이며, 이 저장소에는 **패치를 처음부터 다시 만들 수 있는 모든 것**
(번역 데이터·폰트·도구·문서)이 들어 있습니다.

- 기준 버전: 게임 업데이트 **v1.15.0**
- 최신 릴리즈: [**v2.0**](../../releases/latest) — v1.15.0 대응, 2026 로스터 신규 선수·소개문 번역
- ⚠ **구 게임 버전 v1.8.0 지원은 종료되었습니다.** 게임을 v1.15.0으로 업데이트한 뒤 사용하세요.
  (v1.8.0 용 마지막 릴리즈는 [v1.4](../../releases/tag/v1.4) 이며 더 이상 갱신되지 않습니다.)

## 무엇이 번역되어 있나

| 영역 | 내용 |
|---|---|
| 실행파일 `main` | 메뉴·옵션·도움말·업적·능력/특수능력, 이벤트 대사 등 **182,818** 문자열 |
| 실행파일 — 잘림 복구 | 제자리 예산을 넘는 문장 **34,575건**을 죽은 영역에 전체 문장으로 기록해 온전히 표시 |
| 마이라이프 이벤트 대사 | 조각 조합이 아닌 **완성 문장 5,243개**로 표시 (아래 *조각 조합 문제* 참고) |
| `RES00/RES10.RDB` | NPB 실존 선수명, 팀·구장명, 선수 소개문, UI 라벨 등 **55,186** 문자열 |
| 폰트 | 한글 글리프로 재구축한 폰트 2종 (`COMMON_2D`, `COMMON_2D_2ND`) |

### 조각 조합 문제란

이 게임의 이벤트 대사는 **단어 조각을 순서대로 이어붙여** 문장을 만듭니다. 일본어는 이 방식이
자연스럽지만 한국어는 앞 단어에 따라 조사(은/는·이/가)가 바뀌어 `오늘은은 기다림에 기다림던
입단회견` 같은 결과가 나옵니다. 이 프로젝트는 실행파일의 재배치 테이블(포인터)을 조작해
**첫 조각 자리에 완성된 한 문장을 표시**하고 나머지 조각을 빈 문자열로 만드는 방식으로 해결했습니다.
자세한 원리는 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## 저장소 구성

```
data/                        번역·폰트 원본 (이 프로젝트의 실질적 결과물)
  번역_마스터.json            ★ 단일 소스. exe / exe_pool / exe_ext / rdb 네 섹션
  hangul_to_hanja.tsv        한글↔한자 글리프 인코딩 테이블(폰트와 짝)
  rdb_residual.pack          폰트 글리프·번역 이미지 등 텍스트로 표현 못 하는 차이
  마이라이프_대사.json         마이라이프 씬 구조 + 일본어 원문 + 조각 매핑(참고용)
  전체대사_재구성.json         전 모드 대사 씬 재구성본(참고용)
tools/                       파이썬 도구 일체 (빌드·주입·추출·검증)
  port/                      게임 업데이트 간 좌표 이식 도구(1.8.0 → 1.15.0 에 사용)
patch/                       패치적용.bat, xdelta3.exe
docs/                        문서
```

> `번역_마스터.json` 하나만 고치면 실행파일과 RDB 양쪽에 반영됩니다.
> **부트스트랩 바이너리가 더 이상 필요 없습니다** — 베이스 실행파일까지 마스터에서 결정적으로
> 재생성됩니다(v1.4까지 있던 `bootstrap/main-safe28.xdelta`는 제거되었습니다).

## 알려진 잔여 사항

- **분기 대사**: 조건에 따라 문장 중간부터 표시되는 대사는 아직 조각 조합으로 남아 있습니다
  (진입점이 이벤트 바이트코드에 있어 정적 해독 실패 — [HISTORY](docs/HISTORY.md) 참고).
- 마이라이프 완성문장 중 **4건**은 꼬리 풀 부족으로 조각 표시가 유지됩니다.
- 그래픽에 구워진 텍스트(이미지) 일부 미번역.
- 기존 세이브의 선수명은 세이브에 저장된 값이 표시될 수 있습니다 — 새로 시작을 권장합니다.
