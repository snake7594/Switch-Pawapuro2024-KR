# 실황 파워풀 프로야구 2024-2025 (Switch) 한국어 팬 번역

Nintendo Switch 『実況パワフルプロ野球2024-2025』(eBASEBALL 실황 파워풀 프로야구 2024-2025)의
한국어 팬 번역 패치 제작 프로젝트입니다. **게임 파일은 포함되어 있지 않으며**, 본인이 소유한
게임에서 직접 덤프한 원본 파일에 xdelta 패치를 적용하는 방식입니다.

- 타이틀 ID: `0100d1c01c194000`
- 기준 버전: 2024-2025 시즌 업데이트 v1.8.0 (업데이트 미적용 덤프에는 패치가 실패할 수 있습니다)

## 번역 범위

| 영역 | 내용 |
|---|---|
| 실행파일(main) | 메뉴·옵션·도움말·페넌트/석세스/마이라이프 대사·능력/특수능력·업적 등 UI/대사 전반 |
| RES00/RES10.RDB | 게임 데이터 텍스트(STRING 청크·스캔 문자열·NX SUR 위젯 라벨), **NPB 선수명 13,000+**, 팀/구장명, 선수 소개문, 폰트 |
| 폰트 | 메인/ADD 2종 UNCDFONT를 한글 글리프로 재구축(단일 인코딩 테이블로 통일) |

주요 품질 작업: 대사 조각(색상 단어·루비 어절) 접합부 띄어쓰기·조사 일치 전수 정비(9만+ 접합),
루비 동사 분절 12,375쌍 통합 재번역, 이름읽기 오역 교정, 폰트 미지원 음절 자모 폴백,
고정 레이아웃 문자열 줄폭/줄수 규격 준수(재배치+압축 재번역).

## 적용 방법

1. [Releases](../../releases)에서 xdelta 패치 4종 + `tools.zip`을 내려받습니다.
2. 본인 게임에서 덤프한 원본 4파일을 준비: `main`(ExeFS), `RES00.RDB`/`RES00.RDI`/`RES10.RDB`(RomFS `cdvdroot/`)
3. 전부 한 폴더에 두고 `패치적용.bat` 실행 → `mods/0100d1c01c194000/` 생성
4. 배치:
   - **Ryujinx**: `mods/contents/0100d1c01c194000/` 아래에 그대로 복사
   - **Switch 실기(Atmosphere)**: `atmosphere/contents/0100d1c01c194000/exefs/main`, 같은 위치 `romfs/cdvdroot/RES00.RDB` 등 (폴더명 소문자 주의)

## 저장소 구성

- `tools/` — 제작에 사용한 파이썬 툴킷 (RDB/RDI 암복호·리팩, 폰트 재구축, 텍스트 추출/주입, 대사 접합부 정비 등)
- `patch/` — 패치 적용 스크립트(`패치적용.bat`)

### 주요 기술 문서(요약)

- **RDB/RDI**: 파일별 XOR 키스트림(involution) + zlib9 슬롯. `rdblib.py`의 `crypt_fast`는
  키스트림의 GF(2) 선형성을 이용한 numpy 블록 벡터화(~83MB/s).
- **폰트(UNCDFONT)**: FNTL(56×56)/FNTS(44×44) 4bpp 고정 슬롯, 12B 레코드(유니코드/오프셋/메트릭).
  한글은 한자 코드포인트 셀에 매핑(가→亜 테이블 단일화). FNTL 글리프 데이터는 레코드 오프셋 −6바이트 위치.
- **대사 구조**: .rodata의 24B 레코드 테이블(char*, 슬롯 ptr, 0x403)이 표시 순서대로 조각을 나열,
  렌더러가 인라인 연결 + 자동 줄바꿈. 색상 단어/루비 어절도 독립 레코드.
- **exe 주입**: 제자리 치환(+후행 NUL 슬랙) → 부족 시 '죽은 zero-run 풀'(데이터 포인터·코드 참조 배제)
  재배치 + 포인터 갱신. `.text`/헤더 불변 보장.
